# Translation Review Fixes Design

## Scope

修复代码审查中确认的功能和工程问题：属性变更回填、重试分类、LLM 响应完整性、中文简繁语言判断、隐藏内容收集、目标语言切换、国际化覆盖、配置 URL 校验、文档和测试工程化。补充回归测试和验证脚本。

## Explicitly preserved behavior

不修改 `src/background/llm.js` 中现有请求正文和响应正文日志行为。第 6 点审查意见明确排除在本次范围之外。

## Behavior

- 属性收集同时检查属性根节点和后代节点。
- 收集器跳过 `hidden`、`aria-hidden="true"` 和非渲染祖先内容。
- 仅对明确的临时错误重试：HTTP 429 和 5xx；4xx、解析错误、响应格式错误、超时和网络错误不重试。
- LLM 批次必须为每个请求项返回非空字符串；不完整响应不缓存、不上屏，并按错误策略处理。
- 普通语言按主语言匹配；中文区分简体与繁体脚本/地区。
- 已翻译页面的目标语言发生变化时，下一次点击自动恢复旧译文并立即按新语言翻译；语言未变化时保留恢复行为。
- Popup、Options、content 和 service worker 的用户可见文案统一使用现有 i18n 机制。
- 配置 URL 必须是绝对 `http:` 或 `https:` URL；保留本地 HTTP 服务兼容性。

## Validation

为属性变化、隐藏内容、HTTP 4xx/5xx/429、空/部分响应、中文语言匹配、目标语言切换、国际化和 URL 校验增加测试。运行完整 Vitest、静态语法检查和 manifest/资源校验。

## Non-goals

不重写整体翻译状态机，不改变缓存淘汰策略，不改变现有请求/响应正文日志，不引入真实远程 API 测试。
